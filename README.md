# 📚 Student Task Manager

A simple, responsive, and user-friendly web application designed to help students manage their daily study tasks efficiently.

## 🌐 Live Demo

🚀 **Visit Website:**  
https://tak174271-ctrl.github.io/Student-task-manager/

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 📱 Responsive and user-friendly interface
- 🎯 Simple task management

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 🎯 Project Objective

The objective of this project is to develop a simple task management system that helps students organize their daily study activities, track completed tasks, and improve productivity.

## 🚀 How to Use

1. Open the live website using the link above.
2. Add your daily study tasks.
3. Edit tasks whenever required.
4. Mark tasks as completed.
5. Delete tasks that are no longer needed.
