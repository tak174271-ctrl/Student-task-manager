# 📚 Student Task Manager

A simple and responsive web application to manage daily study tasks.

## ✨ Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Simple and user-friendly interface
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
